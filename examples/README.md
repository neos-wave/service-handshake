# SH-1.2 examples

The three declaration files reproduce the complete JSON examples in Technical Specification §9. All identifiers and evidence references are illustrative.

- `assisted-consumer.json`: consumer declaration prepared with assistance; authority remains unresolved.
- `brand.json`: company declaration represented by human staff in Mode 3.
- `triadic-utility.json`: family-configured agent with namespaced utility actions and unresolved delegation.
- `refund-held.json`: compatible refund held pending authority checks.
- `voucher-denied.json`: voucher proposal denied because of a consumer boundary.
- `safeguarding-escalated.json`: specialist referral with the authority restriction preserved.

Assessment digests bind the exact bytes of the relevant declaration files. Structural validity does not establish genuine evidence, permission or execution.
